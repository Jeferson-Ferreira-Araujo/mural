# mural
## Etapa 1 — base visual

Next.js 15 + TypeScript + Tailwind v4, exportado como site estático (`out/`). Sem backend; dados mockados em `src/data/mock.ts`.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # gera ./out
```

Imagem da lousa: `public/img/quadro-desktop.webp` (original em `imagens/quadro-desktop.png`).
